# Paid Ads — Winning Angles Library (Mar 2026 onward)

This folder stores the **retrieval-ready context** we build from:

- live platform performance pulls (Meta + Google) starting **2026-03-01**
- Salesforce outcomes (MQL/SQL/pipeline/closed-won) starting **2026-03-01**

The goal is to let paid-ads creative and copy agents reference **historically winning**:

- angles and hooks
- CTA patterns
- headline/description/primary-text patterns
- audience + placement context
- creative format context (image/video, RSA assets, extensions)

## Files

- `meta_mar2026_onward.md`: distilled winners for Meta (ads + creative/copy)
- `google_mar2026_onward.md`: distilled winners for Google (asset-level + ad-level)
- Optional structured artifacts (if/when needed):
  - `meta_assets.json`
  - `google_assets.json`

## Scoring principle (aligned to pacing model)

When ranking “winners”, we bias:

- **85% ROI** (Salesforce): \(pipeline + 2 \times closed\_won\)
- **15% in-platform performance** (Meta/Google): efficiency + engagement + conversion signals

This library should include confidence markers (sample size, spend, conversions) to avoid overfitting.
