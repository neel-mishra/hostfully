## 4. Safe Zones & Layout Grid

### Safe Zone Measurements (all sizes)

| Size | Dimensions | Safe Content Zone | Top | Bottom | Left/Right | Overlay Elements |
|------|------------|-------------------|-----|--------|------------|------------------|
| LinkedIn Square | 1080 x 1080 | 960 x 900 | 90 px | 90 px | 60 px | UI crops possible near edges |
| LinkedIn Landscape | 1200 x 628 | 1080 x 500 | 64 px | 64 px | 60 px | Interface labels beneath image |

### Recommended Layout

- **Logo zone:** top-right
- **Headline zone:** upper-left
- **Stat/number zone:** center-left or center
- **CTA zone:** lower-left
- **Background focus:** progression arrow from left to right

### Designer Notes

- Use modular card components so variants can be remixed quickly.
- Reserve a clean area for optional metric overlays in future versions.
- Keep visual pacing energetic but uncluttered.
