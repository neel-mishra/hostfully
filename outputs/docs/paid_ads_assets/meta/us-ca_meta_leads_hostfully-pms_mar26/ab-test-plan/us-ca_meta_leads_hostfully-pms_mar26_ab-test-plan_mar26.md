# AB Test Plan - us-ca_meta_leads_hostfully-pms_mar26 (Mar 2026)

## Testing Objective

Improve qualified lead efficiency for Hostfully PMS Meta prospecting campaigns.

## Test 1: Audience Framework

- **Hypothesis:** Advantage+ audience will produce lower CPQL than manual segmented audiences.
- **Variant A:** Advantage+ prospecting
- **Variant B:** Manual control campaign
- **Primary metric:** Cost per qualified lead
- **Guardrails:** Lead-to-SQL rate, frequency, CPM

## Test 2: Creative Angle

- **Hypothesis:** Operational clarity angle outperforms margin-focused angle for cold traffic.
- **Variant A:** One connected system
- **Variant B:** Direct booking/margin control
- **Primary metric:** Qualified lead conversion rate

## Test 3: CTA Language

- **Variant A:** Book Demo
- **Variant B:** See Hostfully PMS
- **Primary metric:** Landing page form completion rate

## Measurement Standards

- Minimum 7 full days per variant before call (or 1,000+ clicks per variant)
- Use same attribution model across all test cells
- Only one major variable changed per test

## Decision Rules

- Promote winner only if:
  - CPQL improves by >=15%, or
  - CPQL is neutral but SQL rate improves by >=10%
- If no clear winner, keep control and test next variable.
